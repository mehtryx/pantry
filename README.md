# Pantry

A personal PWA for tracking household food inventory, grocery lists, and meal planning.

## Status

**Phase 1 — shipping now:** House inventory (multiple locations, sortable/searchable), grocery list with autocomplete and store filter, "put away" flow, three-quantity model with color-coded stock status, dark/light theme, JSON backup export.

**Phase 2 — next:** Recipe library, 9-day meal planner, automatic grocery list reconciliation from planned meals.

**Phase 3:** PWA polish, animations, offline improvements.

## Getting started

See [SETUP.md](./SETUP.md) for step-by-step setup (Firebase, hosting, deploy to phone).

## Tech

React + Vite · Tailwind CSS · Firebase (Firestore + Anonymous Auth) · Cloudflare Pages hosting · vite-plugin-pwa
